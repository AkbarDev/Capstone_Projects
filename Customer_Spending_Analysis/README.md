# Mall Customer Spending & Demographic Segmentation Analytics (PRCE-003)

## 📌 Project Overview
An exploratory and predictive customer analytics project designed to segment retail consumers. By evaluating key attributes—such as Age, Gender, Annual Income (k$), and Spending Score (1–100)—this project provides actionable insights to optimize promotional targeting and customer retention.

---

## 🛠️ Key Technical Highlights
* **Data Processing**: Python, Pandas, NumPy, and PySpark.
* **Exploratory Data Analysis (EDA)**: Demographic distributions, spending patterns across age brackets, and income correlation analysis.
* **Data Visualization**: Matplotlib and Seaborn charts highlighting customer spending clusters.
* **Technical Challenges Documented**: Resolution of PySpark session initialization (`SparkSession.builder`), environment configuration, and distributed DataFrame schema casting.
